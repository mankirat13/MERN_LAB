# HTML & CSS Development Lab

This repository contains lab assignments for **HTML & CSS Development Lab (BCS554)**. The assignments cover Git basics, HTML page creation, HTML elements, CSS styling, layouts, and responsive web design.

## Assignments

### Assignment 1: Starting a Git Repository
- Initialize a Git repository.
- Configure Git username and email locally.
- Create an HTML file, commit changes, and view commit history.

### Assignment 2: Pushing and Cloning a Repository
- Create a bare Git repository.
- Add a remote repository and push commits.
- Clone the repository and view its commit history.

### Assignment 3: Your First HTML Page
- Create an HTML page with a title and heading.
- Use different heading levels and paragraphs.
- Format text using `<strong>`, `<em>`, and line breaks.

### Assignment 4: Divs, Attributes and a Small Fix
- Create page sections using `<div>` elements and classes.
- Use `id` and custom `data-*` attributes.
- Correct errors in an HTML attendance report.

### Assignment 5: Links and Images
- Create links between HTML pages.
- Add images with specified dimensions and descriptive alternative text.

### Assignment 6: Types of HTML Lists
- Create unordered lists.
- Create ordered lists with nested lists.
- Create description lists using `<dl>`, `<dt>`, and `<dd>`.

### Assignment 7: About Me Page
- Build an About Me page using semantic HTML elements.
- Create navigation links to page sections.
- Add a contact link using `mailto:`.

### Assignment 8: Sign-Up Forms and Choices
- Create a sign-up form with name, email, and password fields.
- Add radio buttons and a course dropdown.
- Use required fields, placeholders, and a submit button.

### Assignment 9: Tables with Headers and Footers
- Create tables with captions, headers, and student marks.
- Calculate class averages and display them in a table footer.
- Use `scope` attributes for accessible tables.

### Assignment 10: CSS Fundamentals
- Apply inline, internal, and external CSS.
- Style HTML elements using element, class, and ID selectors.
- Apply text formatting and background colours.

### Assignment 11: Units and CSS Variables
- Work with pixel, percentage, and rem units.
- Define CSS custom properties in `:root`.
- Use variables for colours, spacing, and heading sizes.

### Assignment 12: Box Model, Cards and Scrolling
- Compare `content-box` and `border-box`.
- Create styled cards with borders, padding, and rounded corners.
- Implement scrolling using `overflow: auto`.

### Assignment 13: Flexbox Layouts
- Create a horizontal navigation bar using Flexbox.
- Centre cards using alignment and justification properties.
- Create wrapping card layouts using `flex-wrap`.

### Assignment 14: CSS Grid Layouts
- Create a grid with three equal columns.
- Build a responsive photo gallery using CSS Grid.
- Create a dashboard layout using named grid areas.

### Assignment 15: Responsive Pages with Media Queries
- Build a mobile-first card layout using media queries.
- Make images responsive using `max-width: 100%` and `height: auto`.
- Adjust text sizes using rem units and media queries.

## Technologies Covered

- HTML5
- CSS3
- Git
- GitHub
- CSS Flexbox
- CSS Grid
- CSS Media Queries
